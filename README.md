# 全球经济图谱

一个基于 React、Vite、Express 和 SQLite 的全球经济数据可视化 MVP。当前使用 `server/src/data` 中整理的近似示例数据，数据说明和页面口径以“示例数据集”为准，不代表实时统计发布。

## 当前功能

### 探索地图

- 世界地图展示已收录经济体。
- 按 GDP 总量、人均 GDP、贸易额、GDP 增速切换着色指标。
- 时间轴支持 2000、2005、2010、2015、2020、2023 六个年度切换。
- 支持播放时间轴，观察指标和全球经济规模变化。
- 点击国家查看年度经济概览，并进入国家画像。
- 地图缩放、拖拽和悬浮提示。
- 打开全球贸易网络后，展示主要双边贸易流；选中国家后可聚焦其贸易伙伴。

### 国家经济画像

- 统一通过 `GET /api/country-profile?countryCode=ISO3&year=YYYY` 获取画像数据。
- 国家来自路由参数 `/country/:code`；年份以 URL `?year=` 与全局时间轴状态（zustand）双向同步：画像页底部时间轴切年即时更新地址栏（用户拖动/点刻度 push 历史、自动播放 replace），并同步写全局状态通知世界地图保持对应国家高亮；在探索地图改年份后进入画像也带参还原。
- 页面顶部提供「返回地图视图」（`/?c=ISO3&year=YYYY`，地图恢复高亮国家与年份）与「国家对比 Compare」（`/compare?c=ISO3&year=YYYY`）两个带参入口。
- 浏览器前进 / 后退（popstate）以 URL 为唯一信号还原国家与年份；画像数据按「国家 + 年份」做 TTL 缓存（5 分钟，并发去重、失败不入缓存、重试可绕过），回退到已看过的组合时同步出画、不发请求、图表无缝更新。
- 无论在画像页内切换国家（伙伴国跳转）还是切换年份，未命中缓存的组合都会重新请求（hook 带竞态保护，深链进入不会先用旧年份多发一次请求）。
- 时间轴仅收录离散年度（2000/2005/2010/2015/2020/2023，以 `/api/meta` 为准）。访问未收录年份（如 `?year=2024`）时，请求发出前即吸附到最近年度（2023），并同步纠正全局状态与地址栏，页面顶部给出「2024 年数据暂未收录，展示最近的 2023 年」提示，杜绝“标题 2024 / 数据 2023”的错位；后端对直接 API 调用也采用相同的就近回落。
- 探索地图同样把年份与定位国家写入 URL（`/?year=YYYY&c=ISO3`），刷新、分享链接与前进后退均可还原地图年份、着色与高亮。

### 国家对比（Compare）

- 路由 `/compare?c=USA&c=CHN&year=2020`，状态全部存放在 URL（最多 4 个国家，自动大写、去重），可分享、可前进后退。
- 核心指标对比表（GDP、人口、人均 GDP、增速、进出口、贸易总额，规模类指标自动标出最大值）+ GDP 历史轨迹多折线。
- 时间轴统一切年（push/replace 同口径），所有国家数据复用画像接口与同一套缓存；芯片与表头可点击进入各国画像，国家可随时增删。
- 加载期间展示骨架屏（Skeleton）；404 未知国家与该年度空数据展示友好空态（Empty State），页面不会抛出 undefined 异常。
- 返回数据经 Zod Schema（`client/src/schemas.ts`）校验，核心字段包含国家基本信息、GDP、人口、贸易总额（`summary.tradeTotal = 出口 + 进口`）。
- 页面顶部为「核心指标卡片」：名义 GDP、人口、贸易规模、人均 GDP。数值自动转换 T/B/M/K 单位并千分位格式化，每张卡片展示相对上一个收录年度的同比变化率（↑/↓ 箭头，上一年度缺测时自动再向前取基期），指标缺失统一显示 `--`。
- 紧随其下为「全球位置 Global Position」：GDP、人口、货物出口额的收录经济体排名（第 N / 共 M 名，竞争排名，仅覆盖 43 个经济体，非全球名次）与全球占比，以 SVG 百分比环形图 + 响应式进度条双重呈现；占比分母采用真实全球总量参照值（World Bank / UN / WTO 世界合计，见 `server/src/data/world.ts`），而非收录经济体合计，避免份额系统性偏高；占比、排名或全球总量缺失时统一显示 `--`。
- 两大模块完全响应式：核心卡片桌面 4 列、平板 2 列、移动端单列；全球位置桌面 3 列、≤960px 折叠为单列。
- 展示最新年度 GDP、人均 GDP、人口、出口、进口和贸易差额。
- 展示 GDP、出口与进口、实际 GDP 增速的历史图表。
- 展示主要出口商品、进口商品和主要贸易伙伴。
- 支持从贸易伙伴跳转到伙伴国画像。
- 支持从关联商品跳转到汽车、锂电池、半导体、粮食、石油和手机产业链。

### 全球产业链

- 提供汽车、锂电池、半导体、粮食、石油和手机六类产业链。
- 用阶段流程图展示国家在不同环节的角色。
- 用全球地图展示产业链节点和跨阶段流向。
- 点击节点进入对应国家画像。

## 运行

```bash
npm install
npm run dev
```

- 前端开发地址：`http://localhost:5173`
- 后端 API：`http://localhost:4000`
- 健康检查：`http://localhost:4000/api/health`

生产构建：

```bash
npm run build
npm start
```

数据库首次启动时会自动创建并播种到 `server/data/app.db`。如需重建示例数据：

```bash
npm run seed
```

## 目录结构

```text
client/src/
  components/   地图、图表、时间轴、骨架屏、空态、产业链流程等可复用组件
  hooks/        画像数据流（缓存 + 竞态保护）、画像/探索/对比三页的 URL ↔ 状态同步 hook
  pages/        探索地图、国家画像、国家对比、产业链页面
  api.ts        前端 API 类型和请求层（含 Zod 校验、错误分类与画像数据 TTL 缓存）
  schemas.ts    接口返回数据的 Zod Schema
  store.ts      年份、选中国家、指标和贸易网络状态
server/src/
  index.ts      Express API 和生产静态资源入口
  db.ts         SQLite schema 和数据库初始化
  seed.ts       数据播种脚本
  data/         国家、指标、贸易、商品和产业链示例数据
```

## 已处理的基础问题

- 接口连接失败、未知国家和未知产业链不再无限停留在加载状态。
- 地图点击贸易弧线不会误清空当前选中的国家。
- 时间轴默认年份会根据后端元数据校正。
- 空数据时图例不会显示 `Infinity`。
- 后端增加 `/api/health` 和 API 未匹配路由的 JSON 错误响应。
