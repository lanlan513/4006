# 全球经济图谱

一个基于 React、Vite、Express 和 SQLite 的全球经济数据可视化 MVP。当前使用 `server/src/data` 中整理的近似示例数据，数据说明和页面口径以“示例数据集”为准，不代表实时统计发布。

## 当前功能

### 探索地图

- 世界地图展示已收录经济体。
- 按 GDP 总量、人均 GDP、贸易额、GDP 增速切换着色指标。
- 时间轴支持 2000、2005、2010、2015、2020、2023 六个年度切换。
- 支持播放时间轴，观察指标和全球经济规模变化。
- 点击国家查看年度经济概览，并进入国家画像。
- 地图缩放、拖拽和悬浮提示。
- 打开全球贸易网络后，展示主要双边贸易流；选中国家后可聚焦其贸易伙伴。

### 国家经济画像

- 展示最新年度 GDP、人均 GDP、人口、出口、进口和贸易差额。
- 展示 GDP、出口与进口、实际 GDP 增速的历史图表。
- 展示主要出口商品、进口商品和主要贸易伙伴。
- 支持从贸易伙伴跳转到伙伴国画像。
- 支持从关联商品跳转到汽车、锂电池、半导体、粮食、石油和手机产业链。

### 全球产业链

- 提供汽车、锂电池、半导体、粮食、石油和手机六类产业链。
- 用阶段流程图展示国家在不同环节的角色。
- 用全球地图展示产业链节点和跨阶段流向。
- 点击节点进入对应国家画像。

### 全球资源地图

- 覆盖石油、天然气、锂、稀土、粮食、水资源六类资源。
- 后端以 GeoJSON（FeatureCollection）返回产地坐标列表与主要消费国坐标列表，含生产量 / 消费量数值。
- 底图之上叠加资源分布图层：产地圆点、消费国圆环与资源富集热力画布。
- 支持按资源分类切换图层；切换时先卸载当前图层的点位与热力数据（取消渲染循环、清空数据引用、擦除画布），再挂载新图层，防止跨资源数据叠加导致的内存泄漏和视图重叠。
- 侧栏展示主要产地与主要消费国排行，悬浮点位查看产量 / 消费量明细。
- **资源节点 × 国家角色动态关联标注**：
  - 点击任意产地圆点 / 消费国圆环后，底图以三种语义色动态标注该资源对应的**主要生产国（绿色填充）、主要出口国（青色虚线描边）、高依赖进口国（红色点状描边）**，多角色国家以「主色填充 + 附加角色描边环」叠加呈现。
  - 同步从左下滑入浮层面板，展示选中国家的**年产量、出口比重、对外依赖度百分比**，并按三类角色分组列出全部标注国家，点击可切换。
  - 角色由后端按统一阈值动态判定（年产量 ≥ 最大生产国 6% 为主要生产国、出口比重 ≥ 15% 为主要出口国、对外依赖度 ≥ 40% 为高依赖进口国），而非写死标签。
  - 再次点击底图空白区域、关闭面板或切换其他资源分类时，所有国家标记立即清除，底图恢复默认样式（切换资源同时复用图层卸载流程）。

### 资源贸易航线

- 覆盖石油、天然气、锂、稀土、粮食五类资源的海上与陆路贸易运输航线（水资源以流域内利用为主，无跨区航线）。
- 在资源产地与主要消费国之间按贸易量绘制带方向的弧形连线：海运航线（实线，途经霍尔木兹 / 马六甲 / 苏伊士 / 巴拿马 / 好望角等咽喉点）、油气管道（长虚线）、陆路运输（点线）。
- 连线粗细与年贸易流量正相关（∝ √流量），出口地为空心圈、进口地为实心点，弧线上带流向箭头。
- 叠加沿航线流动的粒子动画，粒子严格由出口国流向进口国（途径点首 = 出口、末 = 进口，粒子参数 t 单调递增）。
- 切换资源时先停止并销毁前一次的 requestAnimationFrame 动画循环（取消动画帧 + 循环令牌失效 + 清空航线与粒子数据 + 擦除画布），再为新资源启动新循环，任意时刻至多一个渲染循环，避免动画叠加导致页面卡顿；页面切后台时自动停帧。
- 跨 ±180° 经线的航线（如美湾 → 东亚）自动在换日处分段绘制，粒子跨线时不产生横贯全图的拖影。
- 悬停航线高亮并查看「出口 → 进口 · 运输方式 · 年流量」明细；支持滚轮缩放、拖拽平移与粒子动画开关；右侧排行面板列出主要航线流量。

## 运行

```bash
npm install
npm run dev
```

- 前端开发地址：`http://localhost:5173`
- 后端 API：`http://localhost:4000`
- 健康检查：`http://localhost:4000/api/health`

生产构建：

```bash
npm run build
npm start
```

数据库首次启动时会自动创建并播种到 `server/data/app.db`。如需重建示例数据：

```bash
npm run seed
```

## 目录结构

```text
client/src/
  components/   地图、图表、时间轴、产业链流程、资源图层、贸易航线图层等可复用组件
  pages/        探索地图、国家画像、产业链、资源地图、资源贸易航线页面
  api.ts        前端 API 类型和请求层
  store.ts      年份、选中国家、指标和贸易网络状态
server/src/
  index.ts      Express API 和生产静态资源入口
  db.ts         SQLite schema 和数据库初始化
  seed.ts       数据播种脚本
  data/         国家、指标、贸易、商品、产业链、资源分布和贸易航线示例数据
```

## 已处理的基础问题

- 接口连接失败、未知国家和未知产业链不再无限停留在加载状态。
- 地图点击贸易弧线不会误清空当前选中的国家。
- 时间轴默认年份会根据后端元数据校正。
- 空数据时图例不会显示 `Infinity`。
- 后端增加 `/api/health` 和 API 未匹配路由的 JSON 错误响应。
